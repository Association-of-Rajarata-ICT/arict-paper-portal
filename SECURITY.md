# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately and do not open a public issue.

Contact:

- [arict@as.rjt.ac.lk](mailto:arict@as.rjt.ac.lk), with a subject starting **Security report**.

Please include:

- A clear description of the issue
- Steps to reproduce
- Any relevant logs or screenshots

Do not include passwords, API tokens, database credentials or private student information in screenshots or logs. For content and conduct concerns, see [Content Reporting](./CONTENT_REPORTING.md).

We will acknowledge reports within 3 business days and provide a status update once the issue is confirmed.

## Supported Versions

The latest version on the default branch is supported for security fixes.
